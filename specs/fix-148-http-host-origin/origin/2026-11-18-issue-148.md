# Origin: #148 (copied 2026-11-18, verbatim)

## Security: the HTTP transport has no Host/Origin check (DNS rebinding) and no authentication

## What happens
With `MEMKERNEL_TRANSPORT=streamable-http`, memkernel serves MCP over HTTP with no `Host` or `Origin` check and no authentication. A web page the user opens can reach the local server through DNS rebinding and read or write the memory store.

The default stdio transport is not affected.

## Cause (checked on `main` at `36975f5`, the mcp 2.x SDK)
- **The SDK leaves the check off by default.** When no `transport_security` is passed, it builds `TransportSecuritySettings(enable_dns_rebinding_protection=False)` (`mcp.server.transport_security`).
- **memkernel passes none.** `run_server` calls `server.run("streamable-http", host=..., port=...)` without transport security.

## Proposed fix
Turn the SDK's host and origin checks on, with the allowed names following `MEMKERNEL_HOST`:
- **A loopback host** (`127.0.0.1`, `localhost`, `::1`): allow `127.0.0.1` and `localhost` (and `[::1]` for IPv6). A foreign `Host` gets 421 and a foreign `Origin` gets 403.
- **A specific non-loopback address:** allow that address, and log a warning that there is no authentication.
- **A wildcard bind** (`0.0.0.0`, `::`): clients send the machine's real name, never `0.0.0.0`, so the allowed names must be given with a new setting, `MEMKERNEL_ALLOWED_HOSTS` (comma-separated). Without it, the check stays off as today, with a warning, so existing Docker setups keep working.

`MEMKERNEL_ALLOWED_HOSTS` adds names in every case. The README says "local only, no authentication", and the CHANGELOG gets a Security entry.

Found while writing the #107 spec (#141).


## Correction found while building (2026-11-18)

Unmodified `main` already refuses a foreign Host (421) and Origin (403) on a loopback bind: `MCPServer` auto-enables the SDK's DNS-rebinding protection when the host is 127.0.0.1, localhost or ::1 and no transport security is passed (mcp/server/mcpserver/server.py). The issue's claim holds only for non-loopback binds.
